# 实施区与验收区边界

> 文档版本：v1.1；当前状态：边界规则已冻结；Reviewer：gjg；决策人：gjg；冻结日期：2026-09-12（v1.0）；升版日期：2026-09-15（v1.1）。变更依据：CHG-20260915-001。

## 1. 目的

物理隔离实施材料与正式验收材料，防止实施执行者读取、修改或针对隐藏题目优化实现。

## 2. 实施区

实施区可以包含规范、PRD、已冻结契约、接口事实记录、实施任务包、实现文件和公开开发自检。

实施区不得包含：

- 正式验收题全文；
- 隐藏初始数据；
- 隐藏终态断言；
- 正式评分脚本的判定细节；
- 出题会话上下文。

实施区实际路径：`D:\second`。

## 3. 验收区

验收区包含冻结任务集、初始数据与快照、重置能力、终态断言、评分规则和验收运行记录。

实施执行者对验收区没有写权限；正式实现会话的工作目录不得包含验收题文件。

验收区实际路径：`D:\second-acceptance`。

### 3.1 验收区目录清单

下表冻结验收区的固定目录名、内容与访问属性；验收材料的位置和访问控制以本清单为准（总则 §15.1）。

| 目录 | 内容 | 访问属性 | 现状 |
|---|---|---|---|
| `task-sets/` | 冻结任务集 | 隐藏（实施主体 Deny） | 已存在（B00 建立，含隔离哨兵） |
| `assertions/` | 终态断言 | 隐藏（实施主体 Deny） | 目录已建、内容待产生 |
| `runs/` | 验收运行记录 | 隐藏（实施主体 Deny） | 目录已建、内容待产生 |
| `snapshots/` | 初始数据与快照 | 隐藏（实施主体 Deny） | 已存在（含基线快照；ACL 已于 2026-09-15 改 Deny 并重拍证据） |
| `reset/` | 重置能力（恢复脚本） | 受控（实施主体 Modify） | 已存在（restore-snapshot.sh） |
| `evidence/` | 原始证据（脱敏前原始输出） | 受控（实施主体 Modify） | 已存在（EV-B00-* 原始输出） |
| `candidates/` | 候选验收场景（冻结后迁入 task-sets/） | 对实施主体 Deny；盲出题主体可写 `candidates/C01a/` | 未建 |

访问属性说明：

- **隐藏**：对实施主体（b00-impl）施加 Deny（`(OI)(CI)N`），不可读、不可写；Owner/SYSTEM/Administrators 全权（`(OI)(CI)F`）。
- **受控**：对实施主体授予 Modify（`(OI)(CI)M`），可读写但不得越权（ChangePermissions/TakeOwnership）；Owner/SYSTEM/Administrators 全权。
- 根目录 `D:\second-acceptance` 对实施主体仅授予本目录遍历/读取（`(RX)`，不继承），以便其抵达受控可写的 `reset/`、`evidence/`；隐藏目录不因根目录 RX 而可读。

`candidates/` 为验收区顶级目录 `D:\second-acceptance\candidates\`，不并入 `task-sets/`：候选是冻结前体、task-sets 是冻结终态，属两个生命周期阶段。盲出题主体可写 `candidates/C01a/`，对实施主体 Deny；C01b 覆盖审查后冻结的任务集迁入 `task-sets/`。

已办结（2026-09-15）：`snapshots/` 的 ACL 已由 Owner 以 icacls 改为 b00-impl Deny（静态 `(OI)(CI)N`，与 task-sets/assertions/runs 同源），并经 verify-isolation.ps1 负向读取返回 ACCESS_DENIED 重拍隔离证据（见 B00 EV-B00-012 增补）。实施主体不再可读基线快照，snapshots/ 隔离已生效。

## 4. 角色与访问规则

| 角色 | 实施区 | 验收区 |
|---|---|---|
| Implementer | 按任务包授权读写 | 不可见正式题目，不可写 |
| Implementation Reviewer | 可审查授权范围与实施方案 | 不可读取对应正式题目、隐藏数据、评分细节或终态断言 |
| Acceptance Reviewer | 不参与对应实现、实施方案评审、调参或定向修复 | 按验收职责只读；只能向实施侧返回脱敏后的失败类别、公开契约偏差与必要证据 |
| Acceptor | 原则上只读实现交付物 | 按验收职责读写运行记录，不改冻结题 |
| 验收题 Owner | 不参与针对题目的实现优化 | 管理冻结、版本与访问权限 |

任何自然人、服务主体、会话或执行实例一旦读取某一正式验收题正文、隐藏初始数据、评分细节或终态断言，即被视为受该题污染；此后不得参与该题对应能力的实现、实施方案评审、调参或定向修复。更换角色名称或新建但仍携带相关上下文的会话不能解除污染。

## 5. 数据交换

从实施区进入验收区的仅限待测构建、契约版本和公开运行说明；从验收区返回实施区的仅限失败类别、未满足的公开契约或完成条件以及必要的脱敏证据，不返回可导致题目泄露的隐藏断言细节。

## 6. 边界生效条件

- 实际路径已填写；
- Owner 已明确；
- Implementation Reviewer 与 Acceptance Reviewer 已分别指定并验证权限；
- 文件和工作目录访问方式已验证；
- 实施会话无法读取冻结验收题；
- 访问验证已写入 Evidence Manifest。
