## 变更原因与证据

1. 边界 v1.0 冻结时 §2/§3 实际路径为「待项目负责人确定」，但 `D:\second`（实施区）与 `D:\second-acceptance`（验收区）已被 B00、C01a 实际使用。
2. 总则 §15.1 明文「验收材料的位置和访问控制以《实施区与验收区边界》为准」，目录清单的权威落点是本边界文档，事实路径与目录名须冻结进来。
3. 验收区下六个目录 task-sets/assertions/runs/snapshots/reset/evidence 由 B00 `setup-isolation.ps1` 建立，candidates/ 由 C01a 新增约定，均「事实存在但无冻结依据」。
4. 证据：B00 EV-B00-008（独立验收环境 `D:\second-acceptance`）、EV-B00-012 干净态静态 ACL 证据（2026-09-14）；C01a task.md §4/§6.2/§16（candidates/ 约定与「目录名冻结」待决事项）。

- 是否重新冻结：是，本文升版 v1.1 并冻结（冻结对象为实际路径与目录清单字段；v1.0 的角色、数据交换、生效条件等规则不变）。

- 受影响契约/测试/验收结果：无。本变更不涉及 tool 契约、测试或既有验收结果；B00 v1.0 验收结果不受影响。
- 是否重新实施/重新验收：否（纯治理文档字段冻结，无实现或验收环节）。
