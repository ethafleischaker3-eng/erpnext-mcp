- B05 不接入 ERPNext 后端、不调用其 REST API 或数据库，探针与目标客户端均为本机进程，原始输出不含 ERPNext 凭据；但仍须检查探针/客户端会话记录是否含认证头、令牌或完整堆栈，含则 REDACTED；
- 本包无敏感后端原始输出需转存验收区 `D:\second-acceptance\evidence\`；如需留存客户端会话敏感片段，在受控位置登记脱敏引用（总则 §15.1）；
- 合成对象与标记仅为本机探针副作用（标记文件与日志），每次运行前后记录并清理，纳入 Evidence Manifest；
- 本地测试凭据（如有）仅限本地探针连接，迁移共享/生产环境必须更换（§16）。
