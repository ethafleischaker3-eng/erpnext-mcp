## 2. 正式证据记录要求

每条 `EV-A01-*` 必须在执行后补齐：执行者、精确到秒且含时区的时间、操作系统与 shell 版本、完整命令或可复现人工步骤、退出码、预期值、实际值、原始输出位置、原始输出 SHA-256、关联的 A01 冻结版本/哈希及脱敏说明。只有结论而无原始输出的记录不得标记为成功。

## 3. 敏感信息与受控位置

- A01 为客户端能力核查，不涉 ERPNext 后端凭据、数据库或真实业务数据；证据统一为公开脱敏证据，位于 `docs/task-packages/A01/evidence/`；
- 探针副作用仅为本地合成标记文件 `docs/task-packages/A01/probe/state/`，不含真实业务数据或凭据；
- 敏感凭据相关核查仅用占位/合成值，不得记录或输出任何真实凭据值、完整认证头（总则 §6.13）；
- 各证据行原始输出指向 `evidence/W<编号>-<主题>-<时间戳>.txt`，实施时以实际时间戳落盘。
