> 执行会话产出名单后即视为「读过 PRD §2」，不得再充当盲出题会话。

## 任务

从 PRD **仅 §2.1「读写」列 + §2.3 清单** 忠实抽取对象范围边界名单，写入
`docs/task-packages/C01a/object-scope.md`。

**严禁读**：§3.3（tool 清单）、§4（档位推导）以及 PRD 任何其它章节。

## 输出格式

Markdown 表，三列：

| 对象名 | 类别 | 读写性质 |
|---|---|---|

- **对象名**：§2.1「读写」列 + §2.3 清单里出现的对象名，忠实子集，不增不减；
- **类别**：取值「操作允许」或「引用允许」；
- **读写性质**：只取「读写」或「只读」两态。**不设「只出方案」态**（该态与 §4「只出 plan」档同义，会泄露盘点档位）。

自检：预期约 12 个「操作允许」+ 9 个「引用允许」（以 PRD §2 实际为准，数量仅自检，不得凭空增减）。

## 禁止

- 不写 tool 名；
- 不写档位（全自动 / 人确认 / 只出 plan）；
- 不写幂等 / 断言机制口径；
- 不写接口路径；
- 不引入 §2 之外的对象。
