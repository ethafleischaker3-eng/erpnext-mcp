## 2. 目标

在 G01 完整集成验收通过后，汇总项目全部符合性材料并形成正式交付，完成项目收口：

1. **符合性声明**：按《开源后端 Agent 化接入规范》§3.5，产出正式符合性声明——写明本次接入的**符合性等级（L3）**、实际启用的**档位清单及每个写 tool 的档位归属**、每一条 **SHOULD 级条款**的遵守情况、判定「不适用」的条款及理由；
2. **项目交付物汇总**：按总则 §4.6 交付任务包定义，汇总——验证记录（G01 验收报告 + 逐题运行记录位置）、权限矩阵（E01 v1.1）、部署运维说明、回滚手册、验收报告、已知限制及二期事项；
3. **项目完成判定**：核对总则 §16.4 项目完成门槛四项全部满足（冻结任务集连续达 PRD 指标、失败路径全过、符合性材料齐备、所有阻断关闭），将项目标记为「完成」；
4. **登记归档**：更新登记表 H01 行、P00 项目完成状态，产出 Freeze Manifest，作为项目交付的权威收口材料。
