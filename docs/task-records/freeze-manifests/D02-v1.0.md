- 档位 1 验收边界：不设正式验收题、不强制独立验收，正确性由下游 F 包首次使用时验证；要求 F 包实施时逐 tool 核对契约与实际 tool 契合度，发现缺失/歧义即回退 D02 升版；
- 幂等边界依赖 B05 §18.3 冻结值（窗口期 create 300s / confirm·cancel 60s、指纹规则、confirm/cancel 状态断言），D02 只落地为逐 tool 契约口径、不得反向放宽；若 E02 实现时发现该口径不可行，须走变更控制（总则 §12）；
