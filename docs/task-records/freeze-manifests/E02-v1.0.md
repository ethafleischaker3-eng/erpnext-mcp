## 已知限制

- 批次 Owner 身份依赖 B00 §18.3 第 1 条摘要（共用 Administrator、Role/DocPerm 区分主体），确定性身份证据在验收区 D08；若摘要不足以确定性冻结批次归属/授权，须升级向 Owner 澄清，不得推测；
- B05 结论为「无跨重试可关联信号、stdio 进程身份会话级」，批次归属若只能到「会话/进程」粒度，「跨会话查询旧批次」的归属证明可能受限；
- 幂等边界依赖 B05 §18.3 冻结值（窗口期 create 300s / confirm·cancel 60s、指纹规则、confirm/cancel 状态断言），E02 只落地为实现、不得反向放宽；
- create 组窗口期内「同参数合法重复」存在误合并残余风险，无业务引用号的对象无法彻底消除，须在实现契约与符合性声明中如实记录；
- 本包只交付机制底座与接入挂钩，「接入具体 tool」由 D02 契约 + F 包落地；机制与 D01 公共契约共同对齐 B05 §18.3，若漂移由 D02 冻结时核对兜底；
- 机制验证用隔离探针 + 单元测试，不含 ERPNext 真实业务状态；与真实后端的适配由 F 包接入时验证；
